Ocean Portfolio

Ocean Portfolio adalah website portfolio pribadi milik Ayu Cristiana yang menampilkan profil, kemampuan, pendidikan, dan berbagai project yang telah dibuat. Fungsi utama website ini adalah sebagai media untuk memperkenalkan diri serta menampilkan kemampuan di bidang web development, desain, dan teknologi. Website ini bermanfaat bagi pengguna atau pengunjung untuk mengetahui informasi tentang Ayu, melihat skills yang dikuasai, serta melihat project yang pernah dikerjakan. Portfolio ini dibuat menggunakan HTML, CSS, dan JavaScript dengan konsep visual dunia bawah laut yang kreatif dan menarik.

Cara Instalasi

1. Download atau clone source code project.
2. Buka folder project menggunakan Visual Studio Code atau text editor lainnya.
3. Buka file "index.html" menggunakan browser.
4. Website dapat langsung digunakan tanpa instalasi database atau server tambahan.
